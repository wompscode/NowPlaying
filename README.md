# ![logo](logo_64.png) NowPlaying
Shows the currently playing song in your server info bar using [NPSMLib](https://www.nuget.org/packages/NPSMLib) or via D-Bus and latest versions of WINE, and gives you commands to play/pause, skip and go back songs in the currently active player. ~~in Windows~~  
&nbsp;  

Thanks to beerpsi, NowPlaying supports Linux when using up to date versions of WINE. 
&nbsp;
### Dependencies
`NPSMLib` ([nuget](https://www.nuget.org/packages/NPSMLib))  
`Tmds.DBus.Protocol` ([nuget](https://www.nuget.org/packages/Tmds.DBus.Protocol))
`Tmds.DBus.Generator` ([nuget](https://www.nuget.org/packages/Tmds.DBus.Generator))
&nbsp;

### Usage
It's on the main Dalamud repository. Download it using the Plugin installer.
  
### Compiling
It's pretty straight forward. Install all dependencies from NuGet, and have a proper setup XIVLauncher/Dalamud environment. Compile away.
